# CampusHub
A simple web application that helps campus students buy & sell items, report lost & found items, and communicate with others through a basic user system and notifications.

🛠 Tech Stack

  Frontend: React, HTML, CSS
  Backend: Node.js, Express.js
  Database: MySQL

⭐ Features

  User login & registration

  Update profile

  View other users’ profiles

  Post lost or found items

  Post buy or sell marketplace items

  Search and filter items

  Notification system

  Delete your own posts

🔮 Future Improvements

  Direct chat between users

  Online payment gateway

  Support for large number of users
